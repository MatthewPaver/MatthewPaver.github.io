See who gains sensitive cloud access before you approve it.

For cloud security reviewers approving AWS IAM changes.

PolicyLens compares access before and after a proposed change, cites the rule that grants it and checks whether the proposed fix works.

I built
The permission analysis, explanation safeguards and evaluation harness.
Proof
55 documented boundary cases and six tests for misleading or unsupported explanations.
Decision it supports
Approve the change, return it for correction or investigate further.
Limit
It supports a reviewer. It does not model every AWS policy layer or cross-account effect.

Catch schedule conflicts before a change board approves the wrong story.

For project controls teams, PMOs and delivery leads.

ProjectLens places claims from a change pack beside the Primavera schedule dates they rely on, then records what the board accepted or challenged.

I built
Browser-local schedule comparison, evidence provenance and guarded precedent retrieval.
Proof
Every finding links back to a date in the public Northstar schedule.
Decision it supports
Approve, challenge or request more evidence before the board closes the change.
Limit
It does not establish contractual entitlement, causation or forecast certainty.

Give schools, agencies and teachers one view of urgent cover.

A Liverpool service redesign case study.

When a school needs cover today, each party can see who has the request, which checks remain and whether the teacher accepted.

I built

Proof
