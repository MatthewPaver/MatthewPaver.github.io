The interactive demo covers the complete seeded lifecycle across agency, school and teacher views: request cover, rank eligible teachers, send and accept an offer, review compliance and finance, set availability and submit a timesheet.

It runs entirely in the browser. Production identity, messaging, file storage, payments, live updates and operating data remain private.
